Сборка:
```
make
```

Запуск:
```
OMP_NUM_THREADS={} ./var{}
```

Очистка:
```
make clean
```

Вариант 1 — много #pragma omp parallel for
В этом варианте каждый цикл (Ax, невязка, обновление x) запускается с отдельной параллельной секцией. Это удобно и просто, но каждый раз создаются потоки заново — это тратит лишнее время.
Программа работает быстрее, чем последовательная, но немного уступает варианту 2 по скорости.

Вариант 2 — одна общая #pragma omp parallel
В этом варианте вся итерационная часть обёрнута в одну параллельную область. Потоки создаются один раз и работают на всех итерациях. Это снижает накладные расходы и делает работу стабильнее.
Немного быстрее и эффективнее на всех числах потоков.
